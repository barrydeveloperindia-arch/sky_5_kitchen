# System Workflow Master: Professional Line-Wise Set
# Absolute Traceability & Bug-Free Architecture

This document defines the official folder hierarchy for the **Hotel_Sky5** project. All assets, source files, and audit logs must be organized according to this structure for absolute production readiness.

## 01 | Design & Brand Identity
- **/assets**: High-resolution logos, fonts, and brand guidelines.
- **/prototypes**: UI/UX mockups and CSS experiments.

## 02 | Application Source
- **/components**: Modular React components (Admin, Kitchen, Reception).
- **/data**: Static inventory and standard operational data.
- **/hooks**: Custom React logic for automation and state sync.

## 03 | Automation System
- **/audits**: Automated UI and functional audit logs.
- **/coverage**: System test coverage reports.
- **/ledger**: Local JSON database for operational persistence.

## 04 | Digital Assets
- **/media**: Room images, staff photos, and marketing graphics.
- **/qr_codes**: In-room Digital Concierge and UPI payment codes.

## 05 | Production Builds
- **/dist**: Minified, optimized production deployment files.

## 06 | Forensic Logs
- **/attendance**: Daily personnel check-in/out forensic registers.
- **/housekeeping**: Room cleaning audit trails and missing item logs.
- **/revenue**: Daily sales reconciliations and "Charge-to-Room" logs.

## 07 | System Snapshots
- Automated backups of the operational state before major updates.

## 08 | Audit Certificates
- Signed verification reports for monthly compliance.

## 09 | Legal & Compliance
- GST records, vendor contracts, and staff enrollment documents.

## 10 | Engineering Config
- Environment variables, ESLint, and Vite configuration.
